## How I work

I work as a player-coach: hands-on in research, flows, systems and coded prototypes, while mentoring the designers around me. I start from the people and the decision that matters, map where AI can take the routine work and where a person must stay in charge, then write the rules agents follow (their job, limits, confidence bars and handoffs) before designing the screens. I prototype in code early so engineers, clients and users react to something real, and I hand off with annotated specs, design tokens and edge cases. I have taught UX at Pratt Institute and Springboard and mentor designers at Designlab.
